### Devil's Advocate Analysis

Apply this only when the decision affects **multiple components** or **cross-cutting concerns** — not for localized changes.

When proposing a solution for such decisions:
1. **Propose the primary solution** with reasoning.
2. **Devil's advocate perspective** — articulate the strongest counterargument:
    - What could go wrong with this approach?
    - What assumptions are we making?
    - What tradeoffs are we accepting without questioning?
3. **Synthesis** — address the devil's advocate concerns:
    - Which concerns are valid and accepted tradeoffs?
    - Which can be mitigated without changing the core approach?
    - Does the devil's advocate view suggest a better path? If so, why the primary solution still wins (or pivot if it doesn't).

This ensures high-impact proposals are stress-tested before committing.
